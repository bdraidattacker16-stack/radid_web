৩. সৃজনশীল প্রশ্ন
৪র্থ ও ৫ম অধ্যায়: বীজগণিত

x2 − 3x + 1 = 0 একটি বীজগণিতীয় সমীকরণ এবং P = (x − 2) / (x2 − 4), Q = 1 / (x2 + 5x + 6) দুটি বীজগণিতীয় ভগ্নাংশ।

  • ক) x + 1/x এর মান নির্ণয় করো।
    [২]
  • খ) প্রমাণ করো যে, x4 + 1/x4 = 47।
    [৪]
  • গ) P − Q এর মান নির্ণয় করে ফলাফলকে লঘিষ্ঠ আকারে প্রকাশ করো।
    [৪]
৪. সৃজনশীল প্রশ্ন
৬ষ্ঠ ও ৭ম অধ্যায়: সমীকরণ ও সেট

U = {x ∈ ℕ : x ≤ 7}, A = {x ∈ ℕ : x মৌলিক সংখ্যা এবং x ≤ 7}, B = {x ∈ ℕ : x বিজোড় সংখ্যা এবং x ≤ 7} এবং দুটি সমীকরণ: 2x + y = 8, 3x − 2y = 5।

  • ক) A সেটটিকে তালিকা পদ্ধতিতে প্রকাশ করে এর উপাদান সংখ্যা এবং উপসেটের সংখ্যা নির্ণয় করো।
    [২]
  • খ) সমীকরণদ্বয়কে প্রতিস্থাপন বা অপনয়ন পদ্ধতিতে সমাধান করে (x, y) নির্ণয় করো।
    [৪]
  • গ) ভেনচিত্রের তথ্যের আলোকে প্রমাণ করো যে, (A ∪ B)′ = A′ ∩ B′।
