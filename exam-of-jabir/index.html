∴ আসল = ১৩,০০০ − ৩,০০০ = ১০,০০০ টাকা।

(গ) ৩ বছরের সরল মুনাফা, I = ৩,০০০ টাকা।
চক্রবৃদ্ধি মূলধন, C = P(1 + r)n = ১০,০০০(১ + ০.১)৩ = ১০,০০০ × ১.৩৩১ = ১৩,৩১০ টাকা।
চক্রবৃদ্ধি মুনাফা = C − P = ১৩,৩১০ − ১০,০০০ = ৩,৩১০ টাকা।
পার্থক্য = ৩,৩১০ − ৩,০০০ = ৩১০ টাকা।

৩য় অধ্যায়: পরিমাপ

একটি আয়তাকার বাগানের দৈর্ঘ্য প্রস্থের ১.৫ গুণ এবং ক্ষেত্রফল ২১৬ বর্গমিটার। বাগানটির চারদিকে ২ মিটার চওড়া একটি রাস্তা রয়েছে।

  • ক) একটি ত্রিভুজাকার ক্ষেত্রের ভূমি ২০ মিটার এবং উচ্চতা ১৫ মিটার হলে, এর ক্ষেত্রফল কত হেক্টর?
    [২]
  • খ) বাগানটির পরিসীমা নির্ণয় করো।
    [৪]
  • গ) প্রতি বর্গমিটারে ২৫ টাকা দরে রাস্তাটি বাঁধাই করতে মোট কত খরচ হবে?
    [৪]
💡 সমাধান নির্দেশিকা (প্রশ্ন ২):
(ক) ক্ষেত্রফল = ½ × ভূমি × উচ্চতা = ½ × ২০ × ১৫ = ১৫০ বর্গমিটার।
আমরা জানি, ১ হেক্টর = ১০,০০০ বর্গমিটার।
∴ ক্ষেত্রফল = ১৫০ / ১০,০০০ = ০.০১৫ হেক্টর।
(খ) ধরি, প্রস্থ = x মিটার, দৈর্ঘ্য = ১.৫x মিটার।
প্রশ্নমতে, ১.৫x২ = ২১৬ ⇒ x২ = ১৪৪ ⇒ x = ১২ মিটার।
∴ প্রস্থ = ১২ মিটার এবং দৈর্ঘ্য = ১.৫ × ১২ = ১৮ মিটার।
পরিসীমা = ২(দৈর্ঘ্য + প্রস্থ) = ২(১৮ + ১২) = ৬০ মিটার।
(গ) রাস্তাসহ বাগানের দৈর্ঘ্য = ১৮ + ২(২) = ২২ মিটার।
রাস্তাসহ বাগানের প্রস্থ = ১২ + ২(২) = ১৬ মিটার।
রাস্তাসহ ক্ষেত্রফল = ২২ × ১৬ = ৩৫২ বর্গমিটার।
রাস্তার ক্ষেত্রফল = ৩৫২ − ২১৬ = ১৩৬ বর্গমিটার।

৩. সৃজনশীল প্রশ্ন
৪র্থ ও ৫ম অধ্যায়: বীজগণিত

x2 − 3x + 1 = 0 একটি বীজগণিতীয় সমীকরণ এবং P = (x − 2) / (x2 − 4), Q = 1 / (x2 + 5x + 6) দুটি বীজগণিতীয় ভগ্নাংশ।

  • ক) x + 1/x এর মান নির্ণয় করো।
    [২]
  • খ) প্রমাণ করো যে, x4 + 1/x4 = 47।
    [৪]
  • গ) P − Q এর মান নির্ণয় করে ফলাফলকে লঘিষ্ঠ আকারে প্রকাশ করো।
    [৪]
💡 সমাধান নির্দেশিকা (প্রশ্ন ৩):
(ক) x2 − 3x + 1 = 0 ⇒ x2 + 1 = 3x
উভয়পক্ষকে x দ্বারা ভাগ করে: x + 1/x = 3।
(খ) x2 + 1/x2 = (x + 1/x)2 − 2 = 32 − 2 = 7।
পুনরায় বর্গ করে পাই, (x2 + 1/x2)2 = 72
⇒ x4 + 2 + 1/x4 = 49 ⇒ x4 + 1/x4 = 47 (প্রমাণিত)।
(গ) P = (x − 2) / [(x − 2)(x + 2)] = 1 / (x + 2)।
Q = 1 / (x2 + 3x + 2x + 6) = 1 / [(x + 2)(x + 3)]।
P − Q = [1 / (x + 2)] − [1 / {(x + 2)(x + 3)}]
= [(x + 3) − 1] / [(x + 2)(x + 3)] = (x + 2) / [(x + 2)(x + 3)] = 1 / (x + 3)।
৪. সৃজনশীল প্রশ্ন
৬ষ্ঠ ও ৭ম অধ্যায়: সমীকরণ ও সেট

U = {x ∈ ℕ : x ≤ 7}, A = {x ∈ ℕ : x মৌলিক সংখ্যা এবং x ≤ 7}, B = {x ∈ ℕ : x বিজোড় সংখ্যা এবং x ≤ 7} এবং দুটি সমীকরণ: 2x + y = 8, 3x − 2y = 5।

  • ক) A সেটটিকে তালিকা পদ্ধতিতে প্রকাশ করে এর উপাদান সংখ্যা এবং উপসেটের সংখ্যা নির্ণয় করো।
    [২]
  • খ) সমীকরণদ্বয়কে প্রতিস্থাপন বা অপনয়ন পদ্ধতিতে সমাধান করে (x, y) নির্ণয় করো।
    [৪]
  • গ) ভেনচিত্রের তথ্যের আলোকে প্রমাণ করো যে, (A ∪ B)′ = A′ ∩ B′।
    [৪]
💡 সমাধান নির্দেশিকা (প্রশ্ন ৪):
(ক) U = {1, 2, 3, 4, 5, 6, 7}। মৌলিক সংখ্যা নিয়ে A = {2, 3, 5, 7}।
উপাদান সংখ্যা n = 4; উপসেটের সংখ্যা = 24 = 16টি।
(খ) 2x + y = 8 ⇒ y = 8 − 2x ...(i)
(ii) নং সমীকরণ: 3x − 2(8 − 2x) = 5 ⇒ 7x = 21 ⇒ x = 3।
(i) নং এ মান বসিয়ে: y = 8 − 2(3) = 2। নির্ণেয় সমাধান: (x, y) = (3, 2)।
(গ) B = {1, 3, 5, 7}।
A ∪ B = {1, 2, 3, 5, 7} ⇒ (A ∪ B)′ = U \ (A ∪ B) = {4, 6}।
A′ = {1, 4, 6}, B′ = {2, 4, 6} ⇒ A′ ∩ B′ = {4, 6}।
∴ (A ∪ B)′ = A′ ∩ B′ (প্রমাণিত)।

  • ক) প্রচুরক শ্রেণি কোনটি এবং উক্ত শ্রেণির মধ্যমান নির্ণয় করো।
