কারণ:

অপরদিকে, শ্রেণির শিক্ষার্থীদের 'গড় নম্বর ১৫' একটি একক সংখ্যা হলেও তা শ্রেণির সকল শিক্ষার্থীর প্রাপ্ত নম্বরের সমষ্টিগত বৈশিষ্ট্য প্রকাশ করে এবং এটি তুলনাযোগ্য। অতএব, তথ্যটি পরিসংখ্যানের অন্তর্ভুক্ত।
উত্তর: "ষষ্ঠ শ্রেণির শিক্ষার্থীদের গড় নম্বর ১৫" তথ্যটি পরিসংখ্যান বোঝায়।

৩. প্রাপ্ত নম্বরের গড় নির্ণয়:
আমরা জানি, গড় = উপাত্তসমূহের সমষ্টি ÷ উপাত্তসমূহের সংখ্যা

উপাত্তসমূহের সমষ্টি = ১০ + ১১ + ১২ + ১২ + ১৩ + ১৪ + ১৫ + ১৫ + ১৫ + ১৬ + ১৬ + ১৭ + ১৮ + ১৯ + ২০

∴ নির্ণেয় গড় = ২২৩/১৫ = ১৪.৮৭ (প্রায়) বা ১৪১৩/১৫।

১. মধ্যক নির্ণয়:

১০, ১১, ১২, ১২, ১৩, ১৪, ১৫, ১৫, ১৫, ১৬, ১৬, ১৭, ১৮, ১৯, ২০।

মধ্যক = (n + ১)/২ তম পদের মান
= (১৫ + ১)/২ তম পদ = ১৬/২ তম পদ = ৮ম পদের মান।
সাজানো উপাত্তের ক্রমানুসারে ৮ম পদটি হলো ১৫।

৩. মধ্যক নির্ণয়:
এখানে উপাত্তের সংখ্যা, n = ১০, যা একটি জোড় সংখ্যা।
আমরা জানি, উপাত্তের সংখ্যা জোড় হলে,
মধ্যক = [n/২ তম পদ + (n/২ + ১) তম পদ] ÷ ২
= [১০/২ তম পদ + (১০/২ + ১) তম পদ] ÷ ২
